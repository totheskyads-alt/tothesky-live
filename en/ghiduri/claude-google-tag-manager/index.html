What Claude does once it is connected

Claude reads every tag, trigger and variable in your container. It creates conversion tags and their triggers in a draft workspace, checks that the setup is correct, opens your site in Chrome and tests that each event fires. Then it tells you what works and what doesn't. You review the changes and press publish. You don't need technical knowledge to use it: you tell Claude what you want to measure, and it does the rest.

The two tools behind it

The first is a GTM connector (an open source MCP server), which gives Claude access to your container: tags, triggers, variables and versions. The second is Chrome DevTools MCP, free, from the Google Chrome team. With it, Claude opens your site and sees the requests that leave the page, what lands in the dataLayer and any errors in the console. The GTM connector builds the tag, and Chrome DevTools proves it fires. The downloadable guide shows the exact steps for both.

How I set up a conversion now

Claude creates the tag and trigger in a draft workspace, not in the main one. It opens the site in Chrome and does the action, for example submitting the form or reaching the thank-you page. It checks three things: that the conversion request goes out to Google Ads, GA4 or Meta, that the dataLayer event has the right value and currency, and that there are no console errors. Then it gives me a short list of what fired and what didn't. I review and publish.

What it doesn't do, and where to be careful

Claude knows GTM, but it doesn't know which action is worth money in your business. You tell it that. It can publish on its own, but I don't let it: it drafts and tests, I publish. A tag that exists isn't a tag that fires, so I run the Chrome test every time. And one trap in the setup: if you leave the Google Cloud app in testing mode, access expires after 7 days. The guide shows how to avoid it.

In short

Connect both tools once, start with an audit of your container, then let Claude build and test in a draft workspace. The last click, publishing, stays with you.
